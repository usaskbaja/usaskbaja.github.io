# usaskbaja.github.io

This repo only redirects the old `usaskbaja.github.io` address to the USask Baja SAE website.
Every page (including old links like `/team.html`) is sent to the same page on the new site.

The website itself lives in the private `usaskbaja/website` repo.
To change where visitors are sent, edit the address in both `index.html` and `404.html`.
